* 플레이어가 들고 있는 무게(인벤토리+툴 바)에 따라 이동 속도와 스태미나 소모량이 변화함.
----------------------------------------------------------------------------
기준무게 = 최대무게 / 2

이동 속도 공식 = 이동 속도 * ( 1 / ( 1 + ( 현재무게 / 기준무게) ) )
스태미나 소모 공식 = 소모량 * ( 1 + (현재무게 / 기준무게) )

이동 속도 공식 적용 : Walk, Run, Crouched 속도
스태미나 소모 공식 적용 : Run, Jump 스태미나 소모량
