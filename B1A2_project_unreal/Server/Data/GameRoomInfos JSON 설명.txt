[JSON]
-type: 방의 종류
-size: 방의 사이즈
-leftTopPos: 방향별 방의 중심 기준 좌상단 좌표(일단은 2차원 기준이라 z좌표는 0)
=> 방향은 차례대로 Front, Right, Back, Left
=> 방향은 방의 입구가 향하는 방향을 말함
-isCreateItem: 아이템 생성 여부
-isCreateExit: 비상구 생성 여부
-minCreateCount: 난이도별 방의 최소 생성 개수
=> 난이도는 차례대로 Easy, Normal, Hard
-maxCreateCount: 난이도별 방의 최대 생성 개수
-spawnChance: 난이도별 방 추가 생성 확률
=>1이 100%라고 생각하고 0.25(25%)로 적으시면 됩니다.
-f1DoorCount: 1층의 문의 최소, 최대 생성 개수
-f2DoorCount: 2층의 문의 최소, 최대 생성 개수
-f1DoorPos: 1층의 방향별 방의 중심 기준 문의 좌표(1층 z좌표는 전부 0)
=> 맨 첫번째 수는 방향임 [방향, x, y, z]
=> (방에 생성될 수 있는 문의 최대 개수 * 방향 수) 만큼 나와야 함
=> mainRoom: 3 * 4 = 12
-f2DoorPos: 2층의 방향별 방의 중심 기준 문의 좌표(2층 z좌표는 1층의 높이만큼)
=> 1층만 있는 방은 빈칸으로 놔두기
-doorDir: 문이 설치된 방향


-doorDir은 roomDir이 Front일 때 기준으로 작성
-doorDir과 doorPos의 작성 시 같은 문끼리 매칭되도록 순서 주의
-값이 유동적이거나 없는 것들은 전부 0으로 통일 후 무엇인지 따로 알려주세요.


[모델링]
-모든 방은 입구가 정해져 있어야 함 => 입구가 있는 면이 가로이자 정면
-방의 좌표는 입구의 좌표를 기준으로 정해지기 때문에(가로세로 중간X) 모델링할 때 맞춰서 모델링 필요
